## Part B: On-Site Internship Activities (Askari Bank IT Department)

### 1. Introduction
This report documents my first week of internship at **Askari Bank’s IT Department**.  
The primary goal of this week was to understand how banking operations are supported by IT infrastructure and administrative processes.

Under the supervision of the IT team, I observed and participated in various technical activities, helping me connect theoretical concepts with real-world banking IT operations.



### 2. Activities Performed

#### 2.1 Observation of Display and Connectivity Ports
I observed different display ports such as **VGA** and **HDMI**.  
I learned how VGA is an older analog standard, while HDMI is a modern digital interface supporting both audio and video, and why understanding these ports is important for troubleshooting workstation issues.

#### 2.2 Basic System Administration Tasks
I performed and observed tasks such as:
- Disk creation and partitioning
- Renaming computers according to bank naming conventions  

These practices help in system organization, network management, and backup planning.

#### 2.3 System Logs and User Activity Monitoring
I observed how system logs record:
- Login attempts
- Application usage
- Errors and security events  

I learned how monitoring user activity supports security, compliance, and threat detection in banking environments.

#### 2.4 IT Room and Network Infrastructure Observation
I visited the IT room and observed:
- Switches, hubs, routers
- LAN cables and patch panels
- Modems, UPS units, firewalls
- Structured cabling  

I learned how these components work together to provide secure and reliable connectivity between branches, servers, ATMs, and workstations.

#### 2.5 Maintenance and Diagnostic Commands
I assisted in executing diagnostic commands such as:
- `temp` and `%temp%`
- `prefetch`
- `ipconfig`
- `wmic bios get serialnumber`

These commands help in system cleanup, network diagnosis, and asset management.


#### 2.6 Hardware Fault Diagnosis
I observed a structured troubleshooting process:
- Checking RAM and cables
- Identifying faulty hard drive
- Escalating to vendor support  

This demonstrated systematic hardware diagnostics.

#### 2.7 Black Screen and Boot Issue Troubleshooting
I learned steps to resolve boot issues:
- `Ctrl + Shift + Win + B`
- `Ctrl + Alt + Delete`
- Automatic Repair and Advanced Options
- Uninstalling recent updates
- Using USB recovery media

#### 2.8 Data Backup and Drive Usage
I learned the importance of saving data on separate drives to protect user data during OS failures or reinstallations.

#### 2.9 Adding Systems to Domain
I observed the domain-joining process:
- System properties configuration
- Domain authentication
- Group and user management via Computer Management  

This ensures centralized control using Active Directory.

#### 2.10 Exporting and Importing Browser Bookmarks
I learned how bookmarks are exported and imported to support system migration and data backup.

#### 2.11 Network Printer Configuration
I observed how printers are:
- Connected to the network
- Assigned IP addresses
- Installed and shared across users  

This allows efficient resource sharing in branches.


### 3. Tools and Technologies Observed
- **Hardware**: Desktops, monitors, switches, routers, UPS, firewalls
- **Operating Systems**: Windows (client & server)
- **Commands**: temp, %temp%, ipconfig, wmic
- **Software**: Oracle, SQL Server, CBS, Active Directory, Kaspersky
- **Devices**: Printers, scanners, biometric systems



### 4. Learning Outcomes
- Improved understanding of banking IT infrastructure
- Practical exposure to system administration
- Hands-on experience with diagnostics and troubleshooting
- Awareness of enterprise software deployment
- Understanding of data backup and domain management



### 5. Challenges Faced
- Understanding complex banking systems
- Working under strict security policies
- Limited access to critical systems
- Diagnosing issues with multiple causes  

These challenges strengthened my problem-solving and analytical skills.



### 6. Conclusion
The first week of internship at Askari Bank was a highly valuable learning experience.  
It provided real-world exposure to IT operations in a banking environment and helped me improve both technical and professional skills, laying a strong foundation for future learning.
